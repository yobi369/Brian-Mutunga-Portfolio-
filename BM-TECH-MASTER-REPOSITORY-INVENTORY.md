## How to read this inventory

This is a complete name-level inventory of the 55 repositories returned by the connected GitHub account listing. It is an initial classification based on repository names and previously discussed project context. It is **not** a README, source-code, security, licence, deployment or commercial-readiness audit.

- **Provisional** means the category and role need confirmation from the repository contents.
- **Maturity: Unassessed** means no maturity claim is being made.
- A repository appearing here does not mean it is owned by a registered BM Tech legal entity, commercially available, production-ready or approved for customer use.
- Client/employer and personal repositories are listed separately so the BM Tech catalogue does not imply they are BM Tech products.
