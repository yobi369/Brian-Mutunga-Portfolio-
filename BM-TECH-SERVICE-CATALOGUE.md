# BM Tech — Service Catalogue

> Technology Products, Software Solutions & Digital Infrastructure

BM Tech builds software products and delivers practical technology solutions for organisations in Kenya and beyond.

This catalogue describes the service areas BM Tech is preparing to offer. Every engagement is subject to discovery, technical feasibility, written scope, capacity confirmation and an agreed quotation. The catalogue is not a promise that every service is available immediately.

## 1. Custom software and web applications

For organisations that need a purpose-built digital workflow or customer-facing application.

**Potential work**
- Business websites and landing pages.
- Internal web applications and workflow tools.
- Portals for customers, staff, members or administrators.
- Existing application improvements, maintenance and feature development.
- Progressive web application (PWA) implementation where appropriate.

**Typical deliverables**
- Agreed requirements and user-flow outline.
- Working application or defined feature set.
- Deployment configuration and handover notes.
- Test evidence for the agreed acceptance criteria.

## 2. Backend systems and integrations

For teams that need reliable application logic, data handling or connections between services.

**Potential work**
- API design and implementation.
- Database schema design and migration planning.
- Authentication and role-based access implementation.
- Third-party service integrations, subject to provider access and terms.
- Data import/export and reporting workflows.

**Typical deliverables**
- API and data-flow documentation.
- Implemented endpoints or integration.
- Environment and deployment guidance.
- Verification against agreed functional and security requirements.

## 3. IT infrastructure and deployment

For organisations that need help getting applications deployed and operated more consistently.

**Potential work**
- Application deployment planning and configuration.
- Cloud-hosted application setup using an agreed provider.
- Environment-variable and secrets-management configuration.
- CI workflow setup and deployment checks.
- Basic operational documentation and troubleshooting.

**Typical deliverables**
- Deployment plan and configuration changes.
- Build/deployment verification available from the selected platform.
- Runbook covering agreed routine operations.
- Handover of access and ownership to the client.

## 4. Cybersecurity foundations and technical reviews

For organisations that need a practical review of application or infrastructure risks.

**Potential work**
- Application configuration and access-control review.
- Basic security posture review of an agreed application or environment.
- Dependency and exposed-secret checks.
- Threat and risk review for a defined workflow.
- Remediation guidance and verification of agreed fixes.

**Boundaries**
- Work is limited to systems the client owns or is explicitly authorised to test.
- Scope, methods, test windows and exclusions must be agreed in writing before testing.
- No claim of certification, formal penetration-test accreditation, regulatory compliance or guaranteed security is implied.
- Security testing that could disrupt systems requires explicit approval and a documented safety plan.

## 5. Technical consulting and engineering support

For founders, small businesses and teams that need help making technical decisions or moving a project forward.

**Potential work**
- Technical discovery and architecture review.
- Repository and codebase assessment.
- Product feasibility and delivery planning.
- Engineering documentation and handover support.
- Scoped troubleshooting and implementation support.

**Typical deliverables**
- Findings and prioritised recommendations.
- A proposed implementation sequence.
- A written scope for any follow-on build work.

## Engagement options

Each project is quoted after discovery. BM Tech does not publish fixed prices until the scope, risk, delivery effort and support expectations are understood.

| Engagement | Best suited to | Commercial basis |
|---|---|---|
| Discovery and assessment | Unclear requirements or an existing system needing review | Fixed, agreed discovery scope |
| Defined implementation | A specific website, feature, integration or deployment | Milestone-based quotation |
| Ongoing support | A system requiring recurring maintenance | Monthly or time-bounded agreement |
| Advisory session | A focused technical decision or review | Agreed session fee and duration |

A quotation should identify:
- Deliverables and explicit exclusions.
- Milestones, dependencies and client responsibilities.
- Price, currency, taxes where applicable and payment schedule.
- Acceptance criteria and revision limits.
- Hosting, third-party subscriptions and usage charges.
- Warranty or post-delivery support period, if offered.
- Change-request process and termination terms.

No work begins on the basis of an informal estimate alone. The final written quotation and acceptance govern the engagement.

## Client enquiry and delivery process

1. **Enquiry** — The client shares their organisation, problem, desired outcome, timeframe and contact details.
2. **Initial fit check** — BM Tech confirms whether the request fits its current capability and capacity.
3. **Discovery** — Requirements, users, existing systems, constraints and risks are clarified.
4. **Proposal and quotation** — Scope, deliverables, exclusions, schedule, responsibilities and commercial terms are documented.
5. **Approval and kickoff** — Work starts after written acceptance and any agreed initial payment or access prerequisites.
6. **Build and review** — Progress is shared at agreed checkpoints; changes outside scope are assessed separately.
7. **Acceptance and handover** — The client reviews the agreed acceptance criteria and receives the contracted handover materials.
8. **Support** — Any ongoing support is provided only under the agreed support terms.

## Information to include in an enquiry

Please provide:
- Organisation or project name and location.
- Your role and preferred contact method.
- The problem you want solved and who will use the solution.
- Existing website, application or repository links, if relevant.
- Essential features and any integrations required.
- Desired timeframe and known budget range, if available.
- Any security, privacy, hosting or regulatory constraints.

Do not send passwords, API keys, personal records or confidential production data in an initial enquiry.

## Commercial and operating notes

- BM Tech's legal and tax status, contracting entity and invoicing details must be confirmed before a formal contract or invoice is issued.
- All project access should use named accounts and least-privilege permissions wherever practical.
- Client data and intellectual property ownership, permitted portfolio use, confidentiality and third-party licences must be addressed in the written agreement.
- Hosting, domain, messaging, payment-provider and other third-party costs are separate unless explicitly included in the quotation.
- Delivery dates depend on timely client feedback, access, content and third-party services.
- No uptime, response-time SLA, regulatory compliance or security guarantee is offered unless expressly documented in a signed agreement.
